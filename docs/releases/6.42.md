# Meister 6.42

New command `meister purge` (and `MeisterAI purge`) reclaims the space Finder shows as "purgeable" ("löschbar").

- The preview is the default and changes nothing. It shows the purgeable space, local Time Machine snapshots, and how much iCloud data could become cloud-only.
- `--do` thins local Time Machine snapshots and removes local copies of iCloud Drive, Desktop and Documents files. It only touches files that iCloud reports as fully uploaded and that have not changed for 30 days. Files stay in iCloud and in Finder; opening one downloads it again.
- `--days N` and `--min-mb N` adjust the age and size limits. Explicit paths limit eviction to those folders and leave snapshots alone.
- Git repositories, `node_modules`, `.nosync` items and the Trash are never offered. File access time is ignored because Spotlight and iCloud update it.
- Freed space is measured on the data volume after the run instead of being estimated. No sudo is needed.

Photos, Music and system caches that macOS counts as purgeable stay under macOS control.

Validation: new purge Bats suite plus the full quality gate passed. The eviction path was verified on a real uploaded iCloud file, which was downloaded again afterwards. The read-only preview ran on a real Mac and matched Finder's purgeable figure.

Recap: `meister purge` previews and, with `--do`, frees Finder's purgeable space via snapshot thinning and cloud-only iCloud files.
