# Meister v6.22

MeisterAI now shows what a maintenance run reported, which repairs passed a
follow-up check, and which issues remain open. The desktop app and both CLI
programs use the same archived run reports.

- A persistent global preview switch applies to maintenance, settings and
  automation. Full-profile previews show a module plan without running repairs.
- The results dashboard separates actual runs, previews, incomplete runs and
  older reports. It compares compatible completed runs and reports measured
  removed file data without claiming total free disk space.
- Asynchronous output and status queries keep the UI responsive. Cancellation
  waits for the CLI to exit, and stale ownership locks recover after termination.
- Learned repairs require a matching failure and OS context plus a successful
  module retest. Repeated failures suspend a candidate.
- Native Siri/Shortcuts actions read Mac health and the last saved maintenance
  report. They do not start maintenance or claim to perform a live system check.
- Automated gates cover CLI behavior, twin consistency, native macOS tests and
  universal Release builds.

## Install or update

```bash
brew tap maf4711/meister
brew update
brew reinstall maf4711/meister/meister
```

Both `meister` and `MeisterAI` report version 6.22. The attached native macOS
app supports Apple Silicon and Intel, requires macOS 14 or newer, and requires
the updated CLI for maintenance execution. The app is locally ad-hoc signed;
this GitHub download is separate from TestFlight distribution.

Local validation: 90 CLI tests and 36 macOS app tests passed. Siri response
construction and shortcut metadata were verified; spoken Siri dispatch has not
been verified in a normal installed session.
