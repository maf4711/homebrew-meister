# MeisterAI CLI v6.33

Local Apple Mail cleanup is available through `MeisterAI smartinbox` and
`MeisterAI megasmart`, and enabled by default in maintenance profiles.
Apple Foundation Models classify complete locally available contents. Eligible
newsletters older than seven days can move to an existing trash mailbox only
after native identity, content, protection and destination verification.

- Bounded parallel FM workers also share small message groups.
- Local read-ahead overlaps classification; SQLite caches KEEP decisions for exact contents.
- Missing contents stay explicitly unresolved. No direct IMAP access or cloud classification.
- Ambiguous moves are journaled and never blindly replayed.

Validation: shell/twin checks, 183 Bats, 90 Node and 22 Python tests passed before
release preparation. A four-message on-device comparison measured about 11%
less time; this is not a whole-inbox speed claim.

Known limitation: the observed full scan moved zero messages. Newsletter approval
recall remains unresolved, and unavailable local contents are not classified.
Requires compatible Apple Intelligence hardware, enabled on-device models,
macOS 27 SDK for the helper build, and local Mail/automation permissions.

Install: `brew update && brew upgrade maf4711/meister/meister`.
This is a CLI release; the macOS GUI cask is unchanged.

Recap: Local CLI integration and performance changes published; full-inbox
cleanup success and reliable newsletter recall are not yet established.
