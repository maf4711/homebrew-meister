# Meister v6.26

The Apple Intelligence CLI and native app are now named **MeisterAI**. The
**meister** CLI keeps its name and Ollama backend. Existing app preferences and
historical reports remain readable. Homebrew retains a deprecated `meisterSiri`
command alias so existing scheduled jobs continue to run after upgrading.

- Structured, evidence-based diagnoses for Apple Foundation Models and Ollama,
  with a fixed action catalog, bounded requests and explicit failure handling.
- Model-aware Ollama availability, configurable inference limits and thinking
  mode; Qwen3-Coder 30B remains the default after local comparison of eight models.
- Honest repair reporting, corrected recurrence detection, clearer permission
  handling and protected handling of incomplete or untrusted model output.
- Native app identity migration and updated packaging, tests and documentation.

AI repair execution remains opt-in. Model explanations and proposed checks are
not verified facts; actual repair success requires a follow-up verification.

Install or update:

```sh
brew update
brew reinstall maf4711/meister/meister
brew reinstall --cask maf4711/meister/meister-mac
meister --version
MeisterAI --version
```

Recap: MeisterAI replaces the Apple twin's old name; meister retains Ollama with
stronger diagnostics and reporting.
