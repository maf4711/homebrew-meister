# Meister 6.35

## SmartInbox

Daily maintenance now limits fresh Apple FM classification to 32 messages and a soft 60-second budget. Already-running model requests finish before stopping; Mail reads and move verification have their own timeouts. Cached KEEP decisions do not consume the model budget.

Deferred messages remain protected in the inbox. The next maintenance run continues after the last attempted model message, scoped to the account, mailbox and classifier policy. Progress shows completed model work, cache hits, deferred work and unavailable local content separately.

Preview pages pool 100 headers while native reads remain limited to 25 messages. Sparse-candidate tests use half as many model helper launches. Every proposed move still requires current native identity confirmation. A native timeout retains only the affected batch.

For a full read-only check, run `MeisterAI smartinbox preview --full`. The normal manual preview remains unbounded; maintenance uses `--maintenance`.

## AI Updates

Failed updates now log the updater operation, exit code and affected client for AI-Heal. Raw updater output remains suppressed. Homebrew app ownership follows installed artifact paths, avoiding false warnings when ChatGPT packages use the Codex bundle identifier.

## Validation

Regression coverage includes model budgets, cache reuse, continuation and policy changes, deferred-message protection, native confirmation, progress output and update failures.

## Recap

Bounded daily SmartInbox work, visible progress and actionable AI update diagnostics.
