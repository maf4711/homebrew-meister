# Meister v6.24

Daily runs no longer touch the iOS Simulator stack. Reports now carry the
measured bytes they already printed as FIX lines.

- `--auto` / `--quick` skip **Simulator Fix** and **iOS Simulators**. Weekly
  `--deep` still runs them. `MeisterAI simfix` never calls `simctl list` and
  never launches Simulator.app.
- `last.json` `freed_bytes` is filled from measured megabytes (Deep Clean and
  CoreSimulator caches). Successful `cleanup_find_delete` runs increment
  `verified_repair_count` once per call.
- Sleep-blocker warnings name the process. Time Machine warnings point at
  `MeisterAI backup`.
- Homebrew cask `meister-mac` installs notarized **MeisterAI.app**.

```bash
brew tap maf4711/meister
brew update && brew reinstall meister
brew reinstall --cask meister-mac
```
