# Meister 6.39

Maintenance reports now distinguish routine progress and intentional activity
from problems that still need attention.

- Claude Desktop's native installation is checked against Anthropic's release
  feed and code signature. A current, verified app no longer triggers an
  unconditional updater warning. Failed verification and version differences
  remain visible.
- SmartInbox separates the remainder of one maintenance run from cumulative,
  identity-scoped traversal history. Traversal is not proof of complete content
  review. RFC subject-header folding no longer rejects an otherwise matching
  local message. Partial, unreadable and unverified messages remain protected
  and continue to produce warnings.
- `MeisterAI megasmart inspect JOB --limit 25 --offset 0 --json` provides bounded,
  read-only diagnostics for unresolved messages. Native reads are limited to
  15 seconds and stop on the first timeout. Readable text does not verify
  attachments or authorize moving mail.
- Sleep diagnostics recognize specific brief Apple system activities and a
  verified intentional OpenClaw caffeinate LaunchAgent. Unknown or persistent
  assertions and failed checks remain visible; no processes are terminated.
- Documents baseline acceptance verifies an explicitly reviewed snapshot,
  preserves a backup and replaces the baseline atomically. Dry runs do not
  write a baseline, and failed scans cannot be reported as successful checks.

Validation: 241 Bats tests, 136 Node tests, 35 Python tests and 24 offline
evaluation fixtures, plus ShellCheck, Bash syntax and generated-twin parity.
Offline fixtures do not measure live model quality.

Install: `brew update && brew upgrade maf4711/meister/meister`.

The existing macOS app uses the updated CLI. This release contains no new app
binary and does not claim to complete pending mailbox reviews or downloads.
