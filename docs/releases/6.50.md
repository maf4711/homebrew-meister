# Meister 6.50

Two repairs from the unreleased 2026-11-15 work are now part of the release.

**Cache cleanup removes only stale entries and reports honestly**
- Removes cache entries only when nothing inside them changed for `CACHE_MIN_AGE_DAYS` (default 7). A stale folder with one fresh file stays.
- Never touches macOS-managed caches (`com.apple.*`, `CloudKit`), the sealed `/System/Library/Caches`, live temporary roots (`/private/var/tmp`), entries with protective BSD flags, or Homebrew downloads.
- Unreadable roots, failed metadata probes, timeouts and removals that did not actually happen stay warnings with counts; a FIX is reported only for verified removals. This ends the recurring "System cache cleanup incomplete" warning caused by protected system caches.

**Short caffeinate runs are no longer sleep blockers**
- A `caffeinate -t N` (N ≤ 1800 s) is informational when the executable is `/usr/bin/caffeinate`, the arguments are bounded and that assertion's own timeout matches. Unbounded, long, mismatching or foreign assertions remain warnings. No process is terminated.

Validation: 15 cache and 3 caffeinate Bats tests ported from the preserved branch `local/warning-autofix-2026-11-15`. Full quality gate passed.

Recap: cache cleanup and sleep-blocker reporting now distinguish real problems from expected system state.
