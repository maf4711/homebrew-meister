# Meister v6.25

LaunchAgent logs showed the same daily failure: brew/mas not on PATH, then
AI-Heal spam on `/dev/tty`, then a fake Homebrew installer.

- Process PATH always includes `/opt/homebrew/bin`. keepcurrent plists set
  `EnvironmentVariables.PATH` so launchd is not stuck with `/usr/bin:/bin`.
- `ensure_brew` uses the absolute Homebrew binary. The official installer is
  never run without a TTY.
- AI-Heal banners go to the logfile only when there is no TTY (no more
  `Device not configured` on every line of `launchagent_err.log`).
- Package-cache FIX lines use measured before/after MB, not the full cache
  size. Sleep-blocker warnings ignore `powerd`/`coreaudiod`. `_Inbox` files
  younger than 14d are not scored while AufRaum apply is off.
