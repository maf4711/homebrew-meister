# Meister 6.36

- Every public Homebrew CLI invocation updates Homebrew and upgrades Meister before starting.
- Both meister and MeisterAI execute the current installed runtime with the original arguments and exit status.
- Update errors stop startup. Update output stays on stderr so JSON output remains usable.
- Retain old kegs during upgrades for already running processes.
- Package the launcher with Homebrew; no shell functions or local wrappers required.

Install: `brew update && brew upgrade maf4711/meister/meister`.
