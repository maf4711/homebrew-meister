# Meister 6.40

Inbox cleanup has been removed from Meister and MeisterAI.

- Remove SmartInbox/Megasmart commands, local Mail readers, classifier, move engine, inspection tools and maintenance integration.
- Remove automatic Documents `_Inbox` archiving and the AufRaum hook from Docs Order and Autofix, including their configuration and dedicated tests.
- Remove the Inbox claim from the native Autofix action and retire the separate app repository's Mail-preview installer and patches.
- Reject unknown commands before auto-detection and maintenance. Existing inbox command invocations now fail instead of starting a maintenance run.

Stored mail state, messages and Documents files are preserved. Local Apple Intelligence for system diagnosis remains available. Node remains a shared requirement for AI-client version checks.

Validation: 232 Bats tests, Python startup/FM checks, twin parity and the native macOS Release build. The native source is version 6.40.0; the existing app cask remains at 6.32 because this build machine has no Developer ID signing identity. CLI removal takes effect in that app through the updated backend.

Recap: Inbox cleanup code and entrypoints removed; existing user data retained.
