# Meister v6.28

Runtime confirmations answer **yes** on their own. LaunchAgent and GUI runs
no longer abort for a missing TTY or wait on `[y/N]`. Homebrew is non-interactive.
`MeisterAI sudo-setup` installs a shared 2h sudo ticket (`!tty_tickets`).

Install or update:

```sh
brew reinstall maf4711/meister/meister
MeisterAI --version
```

Recap: unattended yes for confirmations; sudo-setup shares one auth across jobs.
