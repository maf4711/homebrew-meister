# Meister 6.49

Time Machine can now be excluded permanently, as requested on 2026-11-15.

- New setting `TM_MONITOR_ENABLED` (default `true`). With `false`, Meister skips the Time Machine module in every profile, including `--deep` and `-a`, makes no `tmutil` query, records no Time Machine finding, and omits Time Machine from `doctor` and `today`, including older log entries. The log on disk stays unchanged. Explicit `backup` stays available.
- The setting existed only as an unreleased local patch; with it missing from 6.47/6.48, "Time Machine: no backups" kept appearing despite the opt-out in `~/.meister/config`.

Validation: 3 new Bats tests, including real `doctor` and `today` runs with a `tmutil` stub that must never be called. Full quality gate passed.

Recap: `TM_MONITOR_ENABLED=false` now removes Time Machine from maintenance, doctor and briefings.
