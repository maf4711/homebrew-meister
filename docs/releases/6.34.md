# MeisterAI CLI v6.34

Every maintenance profile now runs AI Updates before optional modules, including
Quick and runs with Dev Updates disabled. Installed, recognized AI clients are
updated through their existing Homebrew, npm or native installer ownership.

- Refresh Homebrew metadata and include auto-updating AI casks with greedy upgrades.
- Check AI npm packages against latest across Homebrew and installed nvm prefixes.
- Run native Claude, Grok, Cursor Agent and OpenCode updaters where installed.
- Retry failed updates once and verify package versions or native executables.
- Report unmanaged desktop apps and duplicate copies as unverified.
- Preserve read-only commands, dry-run behavior and running client sessions.
- Declare coreutils for bounded update commands on macOS.

Validation: full offline CLI quality gate, focused failure/ownership tests and
installed dry-run previews for both twins across all four maintenance profiles.
Native updater success verifies executability, not independent upstream freshness.
Unmanaged desktop clients without supported unattended updaters still need an
in-app update. Required updates can extend Quick runs beyond the soft time budget.

Install: `brew update && brew upgrade maf4711/meister/meister`.
This is a CLI release; the macOS GUI cask is unchanged.
