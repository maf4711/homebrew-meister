# Meister v6.27

The Apple Intelligence CLI command is **MeisterAI** only. Homebrew no longer
installs a `meisterSiri` command alias. Keep-current LaunchAgents are rewritten
to `/opt/homebrew/bin/MeisterAI`. Historical `last.json` twin names still map
to MeisterAI. The **meister** CLI keeps its name and Ollama backend.

Install or update:

```sh
brew update
brew reinstall maf4711/meister/meister
meister --version
MeisterAI --version
```

Recap: the Apple CLI on PATH is MeisterAI; leftover meisterSiri jobs are migrated.
